# Data Dictionary

| Column | Type | Meaning | Range in generated sample |
|---|---|---|---|
| study_hours | float | Study hours per day | 0.5–8.0 |
| attendance | float | Attendance percentage | 45–100 |
| previous_marks | float | Previous exam marks | 25–98 |
| assignment_score | float | Assignment score | 30–100 |
| exam_marks | float | Target exam marks | 0–100 |

All records are synthetic and generated using a reproducible random seed. They do not describe actual students.
